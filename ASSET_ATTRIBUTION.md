# Asset attribution register

Every non-text asset stored in this repository is listed here. `scripts/check-assets.py` fails CI
if a file under `docs/assets/` is missing from this register.

Policy: original assets first; public-domain/CC0 second; CC BY 4.0 third; anything else only after
the maintainer reviews the exact license terms. **No NC, ND, or ShareAlike assets by default.**
See `MASTER_PROMPT.md` Section 6 for the full policy.
