# AI evaluation, observability, security, safety, and governance

AI systems need evidence that they work and controls that keep them safe. This section covers
evaluation (offline/online, golden datasets, RAG and agent metrics), observability (tokens, latency,
traces, cost, quality dashboards), AI security and safety (prompt injection, jailbreaks, poisoning,
excessive agency, tool abuse, supply chain), and governance against current NIST AI RMF and OWASP
guidance, with versions and dates recorded.

## What you will learn here

- Build an evaluation pipeline with golden sets, regression gates, and human review
- Trace and cost an LLM or agent request end to end
- Threat-model an AI application and apply layered defenses
- Map controls to NIST AI RMF and OWASP LLM/GenAI guidance

**Prerequisites:** [Security architecture](../security-architecture/index.md) and [Agentic AI](../agentic-ai/index.md).
