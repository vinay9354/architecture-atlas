# Generative AI, LLMs, prompt engineering, and context engineering

Large language models (LLMs) changed what software can do and introduced a new set of architecture
decisions: managed versus self-hosted, open versus proprietary, model routing and fallback, cost per
token, latency versus accuracy. This section covers LLM fundamentals (tokens, context windows,
sampling, alignment, hallucination), those architecture decisions, and the practice of prompt and
context engineering, keeping the two clearly distinct.

## What you will learn here

- Explain tokenization, context windows, sampling parameters, and why models hallucinate
- Make model selection, hosting, routing, and fallback decisions with cost and latency numbers
- Design prompts, structured outputs, and tool calls that can be tested and versioned
- Engineer context: select, prioritize, truncate, and retrieve what the model needs

**Prerequisites:** [AI and ML foundations](../ai-ml-foundations/index.md).
