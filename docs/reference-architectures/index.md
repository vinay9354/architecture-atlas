# Reference architectures and architecture frameworks

Frameworks give you a vocabulary and a checklist; reference architectures give you a starting
shape. This section covers the AWS, Azure, and Google Cloud Well-Architected frameworks, cloud adoption
frameworks, and the broader framework landscape (TOGAF, Zachman, ArchiMate, ITIL, COBIT, FEAF, C4, DDD,
Twelve-Factor, NIST CSF, NIST AI RMF, OWASP, FinOps Framework, SRE, CNCF landscape), and it will collect
vendor-neutral reference architectures as the case studies mature.

## What you will learn here

- Explain each framework's purpose, scope, strengths, and limitations
- Run a Well-Architected style review across all pillars
- Use reference architectures as a starting point without copying them blindly

**Prerequisites:** [Architecture fundamentals](../architecture-fundamentals/index.md).
