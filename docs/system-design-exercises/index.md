# System design exercises and the design method

Reading about architecture is not the same as doing it. This section holds the twelve-step design
method used throughout the repository and a graded set of exercises: from a URL shortener and a rate
limiter, through data lakes and fraud detection, to landing zones, multi-tenant SaaS, enterprise RAG,
MCP server platforms, and GPU inference clusters. Each exercise states scale, asks for decisions, and
provides a reference solution with alternatives.

## What you will learn here

- Apply the twelve-step design method to any problem statement
- Estimate capacity, choose storage and messaging, and defend the choices
- Produce context, container, and deployment diagrams for a design
- For AI systems, decide model hosting, RAG versus fine-tuning, autonomy, and guardrails

**Prerequisites:** The core learning path in [Start here](../start-here/learning-path.md).
