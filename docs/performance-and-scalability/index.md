# Performance engineering and scalability

Performance is measured, not assumed. This section teaches latency and throughput fundamentals
(percentiles, tail latency, Little's Law), the techniques that remove bottlenecks, and the capacity
planning method that turns a user count into request rates, storage, bandwidth, and instance counts
with the arithmetic shown.

## What you will learn here

- Read P50/P95/P99 and explain why averages hide problems
- Apply Little's Law and bottleneck analysis to size a system
- Pick scaling and optimization techniques with their costs
- Run load, stress, spike, and soak tests and interpret the results

**Prerequisites:** [Architecture fundamentals](../architecture-fundamentals/index.md).
