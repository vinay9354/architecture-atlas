# DevOps, DevSecOps, CI/CD, IaC, and platform engineering

Delivery architecture decides how fast and how safely change reaches production. This section covers
source control and branching, CI/CD pipeline design and deployment strategies (rolling, blue-green,
canary, progressive delivery), Infrastructure as Code (Terraform, CloudFormation, Pulumi, CDK),
DevSecOps controls, and platform engineering (internal developer platforms, golden paths).

## What you will learn here

- Design a pipeline with security gates, artifact promotion, and rollback
- Choose a deployment strategy from risk and traffic characteristics
- Structure IaC with remote state, modules, environments, and policy as code
- Build a platform as a product with self-service and guardrails

**Prerequisites:** [Cloud architecture](../cloud-architecture/index.md) and [Containers and Kubernetes](../containers-and-kubernetes/index.md).
