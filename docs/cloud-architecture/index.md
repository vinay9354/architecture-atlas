# Cloud and infrastructure architecture

Cloud architecture is infrastructure architecture under a different economic model: elasticity,
pay-per-use, shared responsibility, and programmable everything. This section teaches the service and
deployment models, the building blocks every provider offers, multi-account landing zones, compute
options and sizing, and the principles that transfer between AWS, Azure, Google Cloud, and private
platforms. AWS examples appear where they help; the explanations stay vendor-neutral.

## What you will learn here

- Explain IaaS/PaaS/SaaS/FaaS/CaaS and the shared responsibility model
- Design a multi-account landing zone with shared services, centralized logging, and governance
- Choose compute (VMs, containers, serverless, spot, GPU) and size it from workload data
- Map concepts across providers without assuming similarly named services are equivalent
- Apply the Well-Architected pillars to a design review

**Prerequisites:** [Networking](../networking/index.md) and [Architecture fundamentals](../architecture-fundamentals/index.md).
