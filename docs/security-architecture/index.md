# Security architecture and cybersecurity

Security is a property of the whole design, not a layer added at the end. This section covers
principles and threat modeling, identity and access management (OAuth 2.0, OIDC, SAML, RBAC/ABAC,
workload identity), network and application security, data protection and privacy, infrastructure
and supply-chain security, security operations, and the compliance frameworks that architects must
design for. Attacks are described so you can defend against them.

## What you will learn here

- Model threats with STRIDE and attack trees and derive controls
- Design authentication and authorization for users, services, and machines
- Place network and application controls at the right trust boundaries
- Protect data at rest, in transit, and in use, and manage keys and secrets
- Map a design to compliance requirements and know what evidence auditors need

**Prerequisites:** [Networking](../networking/index.md), [Application and API architecture](../application-and-api-architecture/index.md).
