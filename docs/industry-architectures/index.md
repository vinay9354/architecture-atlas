# Industry-specific solution architectures

Industries share building blocks but differ in what is hard. E-commerce lives with flash-sale
traffic; banking with ledgers, reconciliation, and audit; healthcare with HL7/FHIR interoperability and
patient privacy; media with transcoding and global delivery; IoT with device identity and intermittent
connectivity; logistics with real-time location and optimization. This section shows reference shapes
for each, with fictionalized scenarios.

## What you will learn here

- Identify the defining non-functional requirements of each industry
- Recognize standard integration patterns and protocols per industry
- Adapt generic reference architectures to industry constraints

**Prerequisites:** Most of the Architecture, Data, and Cloud sections.
