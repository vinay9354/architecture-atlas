# Support

## Where to ask

| I want to... | Go to |
|---|---|
| Ask a question about a topic or a design trade-off | [GitHub Discussions](https://github.com/vinay9354/architecture-atlas/discussions) |
| Report an inaccurate or outdated explanation | [Content correction issue](https://github.com/vinay9354/architecture-atlas/issues/new?template=content-correction.yml) |
| Report a broken link | [Broken link issue](https://github.com/vinay9354/architecture-atlas/issues/new?template=broken-link.yml) |
| Report a lab that does not work | [Lab bug issue](https://github.com/vinay9354/architecture-atlas/issues/new?template=lab-bug.yml) |
| Propose a new topic | [New topic issue](https://github.com/vinay9354/architecture-atlas/issues/new?template=new-topic.yml) |
| Report a security problem | Privately, see [SECURITY.md](SECURITY.md) |
| Contribute a page, diagram, or lab | [CONTRIBUTING.md](CONTRIBUTING.md) |

## What this project does not provide

- Personalized architecture consulting, certification exam dumps, or reviews of your company's design.
- Support for the third-party tools taught here (AWS, Kubernetes, Kafka, and so on). Use their
  official support channels; we welcome corrections if our explanation of them is wrong.
- Guarantees of currency. Pages carry a `last_verified` date; cloud services, protocols, and AI
  tooling change quickly. If something looks stale, open a content correction issue.

Maintainers volunteer their time. Clear, specific questions with the page link and what you have
already tried get the fastest answers.
